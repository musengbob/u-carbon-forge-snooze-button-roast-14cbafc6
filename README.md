One line roasting an alarm clock that rings at 6 AM on a Saturday morning.

> My alarm rang at 6 AM on a Saturday like it had a shift to clock into — buddy, it's the weekend, even the snooze button filed for overtime.

Entry for the [Snooze Button Roast bounty on make.fun](https://make.fun/bounty/u-carbon-forge-snooze-button-roast-14cbafc6).

## Run

```sh
node main.ts
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `output/entry.txt` locally). The entry is a single line of at most 200 characters.
